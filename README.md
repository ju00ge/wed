# Буфер текстов

## Как пользоваться
- **Поиск:** вводите слова в любом порядке, регистр и ё/е не важны. Синонимы работают: «развод» найдёт и «расторжение», и «divorce».
- **Коды:** введите номер (например, `11`), и текст сразу скопируется. Список кодов виден на главном экране.
- **Карточка:** «Копировать» копирует текст на выбранном языке, RU/EN переключается в один клик.
- **★** добавляет запись в избранное (оно на главном экране). **#** задаёт свой номер; официальные номера занять нельзя.
- **Красная рамка:**
  - «!!! заполнить перед отправкой» — в тексте есть пропуск `___` или `[ссылка]`. Вставьте данные перед отправкой.
  - «Черновик» — информация не подтверждена.
- **Настройки** (★ и личные номера) хранятся только на этом устройстве. Чтобы перенести их на другое, нажмите «Скачать настройки» → «Загрузить настройки».

## Установка на экран
- **iPhone:** Safari → «Поделиться» → «На экран Домой».
- **Android / компьютер (Chrome):** меню ⋮ → «Установить приложение».

Приложение работает без интернета. При каждом запуске с интернетом оно само подтягивает новую версию; номер версии внизу экрана.
